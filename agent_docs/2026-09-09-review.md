## Astra/Codex 근거

[공식 AGENTS 문서](https://learn.chatgpt.com/docs/agent-configuration/agents-md)는 프로젝트 지침의
기본 합산 한도를32KiB로 설명한다. 기존111KB는 이를 넘는다. 로컬 config에서
`project_doc_max_bytes` 명시는 발견하지 못했으나, 이 확인만으로 모든 실행 환경의 실제 로드량을
단정하지는 않는다. 한도를 올리는 대신 중요한 계약이 짧은 루트 안에 들어가게 했다.

[GPT-6 Astra 공식 지침](https://developers.openai.com/api/docs/guides/latest-model)의
prompting best practices를 확인했다. 지침 충돌·불필요한 승인 대기·과도한 검증을 줄이는 데 맞춰
요청 범위 내 자율 진행, 사용자 요청의 우선순위, 변경 위험에 비례한 검증, 간결한 보고를 명시했다.
모델 가격·추론 설정·가상의 능력 수치 같은 쉽게 낡는 내용을 프로젝트 메모에 넣지 않았다.
전역 Codex 설정이나 설치된 스킬은 변경하지 않았다.

## 발견된 기존 가속 경로 문제

`python src/sim_src_upgrade/origin_sync.py --check`는 **FAIL**:
`EventManager`, `ScenarioManager`의 원본 hash가 가속 사본 기준과 다르다.
이번 지침 수정 이전부터 존재하는 정합 문제이며, hash를 갱신하거나 코어를 수정해 덮지 않았다.
다음 가속 작업에서는 실제 diff를 확인하고 사본 동기화+해당 등가성 검증을 먼저 해야 한다.
이 검토에서 가속 경로의 현재 결과 동치를 PASS라고 주장하지 않는다.

## 유지 방법

새 결론은 연구 상태 문서와 발전사를 갱신한다. 새 코드 함정은 코드 계약, 실행 함정은 운영 문서에 둔다.
